# React JS Practice

A grocery shopping with product browsing, a cart, and Firebase authentication/account pages.

## Dependencies

- Runtime: React, React DOM, React Router, Redux Toolkit, Firebase
- Development: Webpack, Webpack-dev-server, Babel, Babel-loader, CSS Loader, Style Loader, HtmlWebpackPlugin

## Run

```
npm install
npm start
```

Open [http://localhost:3000](http://localhost:3000).
